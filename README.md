# ryppo — чёрное био

Адаптивный сайт Никиты / ryppo: чёрный фон, оригинальная ледяная надпись, полный текст био, стек с подписями и прямые ссылки на Telegram и GitHub. Светлая кнопка Telegram с холодным стеклянным бликом выделяет главное действие. Проекты оформлены отдельными карточками, контакты — строками с разделителями.

Первый экран сохраняет предоставленное фото: чёрный фон, ледяной `ryppo`, `bio` в левом верхнем углу и одна стрелка снизу. Нажатие на стрелку плавно прокручивает страницу к основной информации. При включённом уменьшении движения переход и появление текста происходят без анимации.

## Запуск

### Через Live Server в VS Code

Открой папку `D:\halls_web`, нажми правой кнопкой на корневой `index.html` и выбери **Open with Live Server**. Сборка не нужна: стили, шрифты и изображения загружаются прямо из исходников.

Можно открыть и `dist/index.html`, предварительно выполнив `npm run build`. Относительные пути позволяют запускать сборку как из отдельной папки `dist`, так и из вложенного адреса `/dist/index.html`.

### Через Node.js

Требуется Node.js 22 или новее. Установка зависимостей не нужна.

```sh
npm run dev
```

Открыть http://127.0.0.1:5173.

```sh
npm run build
npm run preview
```

Готовый сайт находится в `dist/`. Его можно разместить на любом статическом хостинге. Команда сборки проверяет локальные ссылки на ресурсы.

## Файлы

- `index.html` — контент и семантическая разметка.
- `styles.css` — оформление и адаптивная вёрстка.
- `public/assets/reveal.js` — короткое однократное появление блоков при прокрутке; учитывает клавиатурный фокус и смену настройки уменьшения движения.
- `public/assets/liquid-glass.js` и `liquid-glass-init.js` — сохранённые файлы прежнего эффекта; к странице не подключаются.
- `public/assets/` — локальные изображения, иконки и шрифты; внешние запросы при просмотре не нужны.

Запотевание и голубые фоновые эффекты убраны; прежний `main.js` не подключается. Стили учитывают `prefers-reduced-motion`. Без JavaScript весь текст и навигация доступны. Стеклянный акцент кнопки выполнен на CSS без размытия и SVG-фильтров. Основной текст — 17–18 px, названия проектов — 20 px, заголовки разделов — 28–36 px. На телефоне навигация занимает отдельную строку, кнопки и карточки выстраиваются в одну колонку.
