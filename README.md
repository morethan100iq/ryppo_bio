# ryppo — ледяное био

Адаптивный сайт Никиты / ryppo в эстетике чёрного льда: оригинальная объёмная надпись, запотевшее стекло, полный текст био, стек и прямые ссылки на Telegram и GitHub.

## Запуск

Требуется Node.js 22 или новее. Установка зависимостей не нужна.

```sh
npm run dev
```

Открыть http://127.0.0.1:5173.

```sh
npm run build
npm run preview
```

Готовый сайт находится в `dist/`. Его можно разместить на любом статическом хостинге. Команда сборки проверяет локальные ссылки на ресурсы.

## Файлы

- `index.html` — контент и семантическая разметка.
- `styles.css` — оформление и адаптивная вёрстка.
- `main.js` — стирание конденсата, переключатель эффекта и сохранение настройки.
- `public/assets/` — локальные изображения, иконки и шрифты; внешние запросы при просмотре не нужны.

Эффект учитывает `prefers-reduced-motion`, отключается кнопкой FROST и не блокирует ссылки или прокрутку на телефоне. Без JavaScript весь текст и навигация доступны.
