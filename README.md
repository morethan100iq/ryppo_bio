# Портфолио

Мой сайт-портфолио.

## Локальный запуск

`npm run dev` — сайт на локальном сервере. `npm run build` — сборка в `dist/` с проверкой локальных ресурсов.

## Перед публикацией

Актуальный текст хранится в `index.html`. Навигация — «О себе / Проекты / Стек / Контакты». Разделы используют общий шаблон `.section-heading`: малый номер Geist Mono и крупный заголовок. Нумерация следует текущему порядку на странице: 01 — О себе, 02 — Стек (внутри блока «О себе»), 03 — Проекты, 04 — Контакты. Названия проектов и технологий сохраняются в оригинале.

Визуальные токены RYPPO находятся в `:root` в `styles.css`: чёрная основа, cyan `#75e4f7`, размеры типографики и фоновая сетка. Декоративные надписи скрыты от скринридеров и обрезаются в отдельном слое; фокус интерактивных элементов не обрезается.

Этап 2: ледяной hero, шапка и контент используют общую ширину `--page-width` и поля `--page-gutter`; вертикальная линия продолжается через секции. В hero остаются короткая подпись и ссылка «01 / О себе» со стрелкой. Parallax ограничен 28 px, обновляется существующим обработчиком прокрутки и отключается при `prefers-reduced-motion`. About сокращён; возраст и класс остаются обычным абзацем. HurmoBot вынесен в отдельный `.featured-project` перед остальными карточками: изображение занимает 60% блока на десктопе, до 860 px блок складывается в одну колонку. Наведение и фокус дают cyan-рамку, увеличение только изображения на 2,5% и смещение стрелки; при уменьшенном движении трансформации отключаются.

Роли шрифтов: `--display` — TT Travels Next для логотипа, крупных заголовков и главного CTA; `--sans` — Cygre для интерфейса, текста, карточек, навигации и обычных кнопок; `--mono` — Geist Mono для нумерации, статусов и технических подписей.

`TT Travels Next Trial Variable.ttf` и `tt-travels-next.css` добавлены из локального архива для личного локального тестирования. Приложенная trial-лицензия TypeType допускает оценочное использование и запрещает встраивать шрифт на общедоступную веб-страницу без письменного разрешения. Перед публикацией получите у TypeType разрешение или Webfont-лицензию.

Cygre Regular/Medium/SemiBold подключены локально в исходном TTF-формате. Комплект: https://www.fonts.uprock.ru/fonts/cygre, автор: https://randommaerks.gumroad.com/l/rm_cygre, условия: `public/assets/fonts/Cygre-EULA.pdf`. Кириллический Geist Mono получен из Google Fonts (v6); лицензия: `public/assets/fonts/OFL-Geist.txt`, источник семейства: https://github.com/vercel/geist-font. Скрипт `scripts/download-assets.mjs` сохраняет кириллицу при повторной загрузке ассетов.

HurmoBot и бот для скачивания видео отмечены как активные (`project-status-live`); LycheVPN, pro100code и wishlist — как архивные (`project-status-archived`). В карточках ботов стоят Telegram-ссылки, указанные автором. Ссылки на отключённую веб-часть LycheVPN нет.

Домен пока не выбран. После его появления задайте переменную окружения `SITE_URL` с публичным адресом и запустите `npm run build`. Сборка добавит canonical, `og:url` и абсолютные URL изображения Open Graph / Twitter. Без переменной остаются относительные пути для локального предпросмотра; корректный шаринг нужно проверить после размещения на публичном адресе.

Проектные изображения хранятся в `public/assets/projects/` в формате WebP, ширина не более 960 px. Тяжёлые исходники в `pic/` игнорируются Git и не попадают в сборку. Анимированный GIF не используется: обложка статична и не создаёт дополнительного движения. OG-картинка `public/assets/og-ryppo.png` имеет размер 1200×630 и использует локальный Unbounded.
