# Портфолио

Мой сайт-портфолио.

## Локальный запуск

`npm run dev` — сайт на локальном сервере. `npm run build` — сборка в `dist/` с проверкой локальных ресурсов.

## Перед публикацией

В `index.html` намеренно оставлены видимые поля `[ВПИШИ …]`: описание, стек, статус и ссылка HurmoBot; публичный репозиторий LycheVPN; статус и ссылка бота для скачивания видео; статусы pro100code и wishlist, а также возможности pro100code. Неподтверждённые ссылки не добавлены. LycheVPN отмечен как сервис в разработке, без ссылки на отключённую веб-часть.

Когда ссылка подтверждена, замените соответствующий `<article class="project-card">` на `<a class="project-card" href="…" target="_blank" rel="noopener noreferrer">` и замените закрывающий тег. Для статусов есть классы `project-status-development` («в разработке»), `project-status-live` («в проде») и `project-status-ready` («готово»); `project-status-unknown` используется только для плейсхолдеров.

Домен пока не выбран. После его появления задайте переменную окружения `SITE_URL` с публичным адресом и запустите `npm run build`. Сборка добавит canonical, `og:url` и абсолютные URL изображения Open Graph / Twitter. Без переменной остаются относительные пути для локального предпросмотра; корректный шаринг нужно проверить после размещения на публичном адресе.

Проектные изображения хранятся в `public/assets/projects/` в формате WebP, ширина не более 960 px. Тяжёлые исходники в `pic/` игнорируются Git и не попадают в сборку. Анимированный GIF не используется: обложка статична и не создаёт дополнительного движения. OG-картинка `public/assets/og-ryppo.png` имеет размер 1200×630 и использует локальный Unbounded.
